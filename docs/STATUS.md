# فتویٰ ایپ — موجودہ صورتحال (30 اکتوبر 2026)

## مکمل
- Books/Library ٹیب: قرآن (عربی + اردو + انگلش)، حدیث، حنفی کتب، تلاش، ماخذ اور حقوق کے بیج۔
- زبان منتخب کرنے والا آپشن ہٹا دیا گیا۔
- قانونی صفحات (Terms, Privacy, Disclaimer, Community Guidelines, Data Deletion, Sources): ایپ کے اندر اور ہوسٹڈ (`artifacts/admin-panel/public/`)۔
- دستخط شدہ APK اور AAB: GitHub Actions میں خودکار، ہر بلڈ پر versionCode = 100 + run نمبر۔
- Keystore بنا کر GitHub secrets میں رکھ دیا گیا۔
- 30 دن بعد پوسٹس کا خاتمہ، براڈکاسٹ نوٹیفکیشن (سرور)، پریمیم ٹیب بار، کراس لینگویج جوابات۔
- دارالافتاء دیوبند کے 1,904 فتاویٰ (`data/kb/darulifta.jsonl.gz`) لائبریری میں شامل ہیں۔

- سپورٹ ای میل (contactfatwaapp@gmail.com) تمام پالیسی صفحات اور ایپ میں شامل ہے۔
- پش نوٹیفکیشن: Firebase پروجیکٹ `fatwa-app-2626a` بن گیا، `google-services.json` ریپو میں اور `FCM_SERVICE_ACCOUNT` GitHub secret میں ہے۔ نیا APK بنانے اور Worker ڈیپلائے کے بعد فعال۔

- سائن اِن اختیاری (Google یا ای میل، "Skip for now")؛ پہلی بار سائن اِن پر خوش آمدید ای میل۔
- پروفائل پر کور فوٹو (2:1، بہترین سائز 1200x600): اپلوڈ، تبدیل یا ہٹانا۔
- ایڈمن ڈیش بورڈ پر ٹریفک (ملک، شہر، پلیٹ فارم، روزانہ اوپنز)۔
- ہر push پر "Check (typecheck)" خود چلتا ہے تاکہ لانچ کریش جیسی غلطی پہلے پکڑی جائے۔

## ڈیٹا بیس: Turso (مفت پلان)
Cloudflare D1 کی مفت حد کی وجہ سے ڈیٹا بیس Turso پر منتقل کر دیا گیا۔ API Worker Cloudflare پر ہی ہے۔
- پروڈکشن: `fatwa-app` (صارفین، پوسٹس، نوٹیفکیشن) اور `fatwa-kb` (علمی لائبریری)۔ اسٹیجنگ کے الگ ڈیٹا بیس ہیں۔
- پرانا پروڈکشن ڈیٹا (3 صارف، 5 پوسٹس، 9 درخواستیں، 1 فتویٰ) درست منتقل ہوا۔
- لائبریری مکمل لوڈ: 183,498 اقتباسات، 40 کتب/ایڈیشن، 300 علماء، دارالافتاء دیوبند کے 1,904 فتاویٰ۔
- مفت حد: ماہانہ 1 کروڑ لکھائیاں، 50 کروڑ پڑھائیاں، 5 GB۔ پوری لوڈنگ میں تقریباً 11 لاکھ لکھائیاں اور 323 MB لگے۔
- تفصیل: `docs/DATABASE_TURSO.md`۔

## ڈیپلائے
GitHub → Actions → "Deploy fatwa-api Worker" → Run workflow → staging یا production۔ ٹیسٹ ناکام ہو تو پچھلا ورژن خود واپس آ جاتا ہے۔
دستی لوڈ: `python tools/kb/kbtool.py <API_URL> <ٹوکن فائل> all data/kb/scholars.xlsx`
